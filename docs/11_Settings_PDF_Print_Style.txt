Add Settings PDF / Print Style editor.

Current issue:
Company needs control over PDF/print branding, headers, footers and disclaimers.

Add Settings -> PDF / Print Style.

Fields:
- Company logo upload/use existing logo
- Header text
- Footer text
- Estimate disclaimer
- Form disclaimer
- Payment terms
- Acceptance note
- ABN/licence/contact details if not already in Company Profile
- Toggle: show logo on estimates
- Toggle: show logo on forms
- Toggle: show footer on estimates
- Toggle: show footer on forms

Use these settings in:
- Estimate/Quote print
- Job Form print
- Completed Form print

Rules:
- Company-scoped
- Owner/Admin only can edit
- Normal users can print using saved style
- Print remains clean and professional
- Do not apply dark/game/seasonal theme to print output

Validation:
- Owner/Admin can save PDF style settings
- Normal user cannot edit settings
- Estimate print uses logo/header/footer/disclaimer
- Form print uses logo/header/footer/disclaimer
- Settings persist after refresh
