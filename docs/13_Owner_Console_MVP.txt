Build Owner Console MVP.

Goal:
Owner needs a dashboard/control room to manage companies, users, login activity and online status.

Important:
- Owner only
- Admin is not enough unless Admin also has Owner permission
- Do not expose this to normal users
- Company-scoped where appropriate
- No mock/demo data
- Do not break existing Team/Settings
- Build and publish after passing

Part 1 - Add Owner Console route

Add sidebar item visible only to Owner:
- Owner Console

Route:
- /owner-console

If non-owner tries to open it:
- show access denied or redirect to dashboard

Part 2 - Owner Console dashboard

Owner Console should show cards:
- Total companies
- Total users
- Active users
- Invited users
- Inactive users
- Online now
- Logins today
- Failed login attempts if available later
- Storage used if available later

If this system only has one company currently:
- Still show company list with one company
- Do not use fake companies

Part 3 - Companies table

Show:
- Company name
- Owner
- Total users
- Active users
- Created date
- Status
- Actions: Open / Manage

For now, Open/Manage can link to existing Settings/Team for that company if multi-company switching is not built yet.

Part 4 - Users table

Show all users Owner can see:
- Name
- Email
- Company
- Role
- Status
- Last login
- Last active
- Online now indicator
- Created date
- Actions: View, Edit role/status if allowed, Deactivate if allowed

Part 5 - Login / activity tracking

Add basic user activity tracking.

Track:
- user_id
- company_id
- event_type: login, logout, page_view optional, failed_login optional if easy
- created_at
- metadata_json optional

When user logs in:
- record login event
- update profile last_login_at
- update profile last_active_at

When user uses the app:
- update last_active_at periodically or on page load/API calls

When user logs out:
- record logout event if possible

Online now:
- A user is online if last_active_at is within last 5 minutes
- Show green dot for online
- Show "Last active X minutes ago" if offline

Part 6 - Activity log

Owner Console should show recent activity:
- User name
- Company
- Event
- Date/time
- Optional detail

For this MVP:
- login/logout/last active is enough
- More detailed events can be added later

Part 7 - Privacy and safety

- Owner can see operational login/activity info
- Do not show passwords
- Do not show session tokens
- Do not show sensitive auth internals
- Do not allow owner to remove their own Owner access
- Keep audit/activity data read-only at first

Part 8 - Database

Add fields if missing:
profiles:
- last_login_at
- last_active_at

New table:
user_activity_events
Fields:
- id
- company_id
- user_id
- event_type
- metadata_json
- created_at

Validation:
- Owner can see Owner Console
- Admin without Owner cannot see Owner Console
- Normal user cannot see Owner Console
- Login updates last_login_at
- App usage updates last_active_at
- Online now shows user if active within 5 minutes
- Logout records event if possible
- Activity log shows real events only
- No fake users/companies
- npm run build
- Publish after passing
