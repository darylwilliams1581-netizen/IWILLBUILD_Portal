Upgrade Signature field to support multiple signers.

Current requirement:
Some forms need more than one person to sign, but the number of people is not known when building the form.

Add a Signature field setting:
- Allow multiple signatures: on/off
- Button label setting, default: "+ Add Signer"

When Allow multiple signatures = off:
- Signature field works as normal:
  - Name
  - Signature canvas
  - Clear button

When Allow multiple signatures = on:
- Form Runner shows:
  - Signature group title
  - Existing signer blocks
  - "+ Add Signer" button
- Clicking "+ Add Signer" adds another signer block
- Each signer block includes:
  - Name input
  - Signature canvas
  - Clear signature button
  - Remove signer button
  - Signed timestamp once signed
- First signer block should appear by default
- Users can add as many signer blocks as needed
- Optional max signer setting can default to 20

Saved answer format:
{
  "type": "signature",
  "multiple": true,
  "signers": [
    {
      "id": "signer_1",
      "name": "Daryl Williams",
      "signatureDataUrl": "data:image/png;base64,...",
      "signedAt": "2026-06-26T10:30:00.000Z"
    }
  ]
}

Validation:
- If required and multiple signatures is off, require one name and one signature
- If required and multiple signatures is on, require at least one completed signer block
- A signer block is only complete when both name and signatureDataUrl exist
- Empty added signer blocks should not block completion unless required and no completed signer exists

Reopen/edit:
- Load all saved signer blocks
- Render saved signature images back into canvas or read-only preview
- Users can add more signers later
- Users can clear/remove signer blocks before completion

Completed/read-only:
- Show each signer with name, signature image and signed date/time

PDF/print:
- Include all signers
- Keep each signer block together where possible
- Do not split a signature image awkwardly across pages

Builder UI:
- In Signature field settings, add:
  - Toggle: Allow multiple signatures
  - Optional input: Button label
  - Optional input: Max signers
- Do not break existing single signature fields
- Existing saved signature fields should default to single signature mode

Build and publish after passing.
