Build Owner Support / Setup Mode.

Goal:
Platform Owner needs a safe way to help customer companies set up IWILLBUILD:
- upload cost guide
- build form templates
- set up users/profiles
- configure permissions
- troubleshoot data
- review setup progress

Important:
- Owner only
- Not visible to normal users
- Not visible to normal Admin unless Admin is also Owner
- Must be audited
- Do not expose passwords or auth secrets
- Do not allow unsafe silent access
- No mock/demo data
- Build and publish after passing

Part 1 - Add Support Mode to Owner Console

In Owner Console, add company actions:
- Open Company
- Support Setup
- View Users
- View Activity

Support Setup opens selected company workspace in support context.

Show a clear banner when Owner is in support mode:
"Support Mode: You are viewing [Company Name]"

Buttons:
- Exit Support Mode
- View Audit Log

Part 2 - Support Mode permissions

Owner in support mode can:
- View company dashboard
- View/create/edit jobs if needed
- View/upload files if needed
- View/edit cost guide
- Build/edit form templates
- Create/invite users
- Edit user profile/permissions
- Configure company profile/settings
- View fleet/forms setup

Owner in support mode cannot:
- See or change user passwords
- See payment secrets
- Delete company permanently unless a separate dangerous action exists
- Remove their own Owner role
- Disable audit logging

Part 3 - Company switching

Add ability for Owner to select a company from Owner Console.

When selected:
- Store support company context for current session
- All company-scoped pages should use selected support company ID instead of owner's default company
- Show visible Support Mode banner on every page
- Exit Support Mode returns to owner's own company/dashboard

If full company switching is too much:
- Start with support setup screens inside Owner Console:
  - Company Profile
  - Users
  - Cost Guide
  - Form Templates
  - Files overview

Part 4 - Audit logging

Every support action must create audit record:
- owner_user_id
- target_company_id
- action_type
- entity_type
- entity_id if available
- before/after summary if available
- created_at

Examples:
- Owner entered support mode
- Owner uploaded cost guide item
- Owner edited form template
- Owner invited user
- Owner changed permission
- Owner exited support mode

Add audit table if needed:
support_audit_events
Fields:
- id
- owner_user_id
- target_company_id
- action_type
- entity_type
- entity_id
- summary
- metadata_json
- created_at

Part 5 - Setup checklist

Add Support Setup checklist per company:
- Company profile completed
- Logo uploaded
- Users invited
- Permissions configured
- Cost guide added
- Form templates created
- Fleet assets added
- First job created
- Files/storage checked
- Dazza company knowledge added

Show progress percentage.

Owner can mark setup checklist items complete manually if needed.

Part 6 - Import helpers

Inside Support Setup, add quick links/actions:
- Import Cost Guide
- Create Form Template
- Invite Users
- Edit Company Profile
- Upload Logo
- Configure PDF Style
- Configure Dazza Knowledge

Do not build complex CSV import unless simple.
For this pass, manual add/edit screens are okay if import is not ready.

Part 7 - Safety / UX

Support mode must be obvious:
- banner at top
- different subtle background/accent
- company name always visible
- exit button always visible

Never make it look like the owner is a normal user without indication.

Validation:
- Owner can open Owner Console
- Owner can select company
- Owner can enter Support Mode
- Banner appears
- Owner can edit that company's settings/templates/cost guide if supported
- Audit events are created
- Exit Support Mode works
- Normal Admin cannot access Owner Console or Support Mode
- Normal user cannot access Owner Console or Support Mode
- No passwords/secrets exposed
- npm run build
- Publish after passing
