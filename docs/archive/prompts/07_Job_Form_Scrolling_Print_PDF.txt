Fix Job Form Runner scrolling and add Print/PDF from Job Forms.

Current issues:
1. Job Form Runner still does not scroll properly to the bottom.
2. There is no Print/PDF function for a form from Job -> Forms.

Part 1 - Fix Job Form Runner scrolling properly

Current layout is still trapping the form content.
The user must be able to scroll the form like a normal web page from top to bottom.

Required:
- Job Form Runner should be a full-page job tab experience, not a trapped inner panel.
- Use normal document/page scrolling where possible.
- User must be able to reach every field and the Save Draft / Complete Form buttons.
- Scrolling must work on mouse wheel, trackpad, phone/tablet touch and keyboard.

Implementation guidance:
- Do not put the form body inside a fixed-height container with overflow hidden.
- Avoid height: 100vh on nested wrappers unless body scroll is correctly handled.
- Remove any overflow-hidden that prevents page scrolling.
- Prefer page content scrolling naturally.
- Sticky header/footer is optional.
- If using sticky footer, add bottom padding to form content, minimum 140px.
- Footer must not cover last fields.
- The browser page scrollbar should move normally.

Validation:
- Create or open a form with at least 12 fields
- Scroll to bottom using mouse wheel
- Scroll to bottom using mobile/touch simulation
- Confirm final field is fully visible
- Confirm Save Draft and Complete Form are reachable
- Confirm no field is hidden behind buttons
- Confirm Job tabs/header do not block scrolling

Part 2 - Add Print/PDF for Job Forms

Add Print/PDF button in Job -> Forms.

Where buttons should appear:
- For completed forms: View, Print/PDF, Reopen/Edit if allowed, Delete if allowed
- For in-progress forms: Continue, Save Draft inside runner, Print Draft optional, Delete

Inside Form Runner:
- Add Print/PDF button in the top right or footer
- If form is in progress, print should show DRAFT
- If completed, print should show COMPLETED

Print/PDF layout:
- Client/professional report style
- Include company logo/name if available, form title, job number, job name, job address/location, completed by, completed date/time and status
- Then print all form answers clearly

Field print behaviour:
- Section Header: bold section divider
- Instruction: show instruction text, no fake input box
- Short/Long Text: print answer text
- Yes/No: print selected answer clearly
- Checkbox: print ticked/unticked
- Single Choice/Multi Select: print selected values
- Date/Date Time: print selected date/time
- Photo/Media: show thumbnails in body, then optional photo album at end if already supported
- Signature: show name, signature image, signed date/time
- Multiple signature field: show all signer blocks

Print styling:
- Hide app sidebar/nav/tabs/buttons
- A4 friendly
- Page margins around 14mm
- Avoid splitting signatures/images awkwardly
- Avoid large empty areas
- Do not use dark theme in print
- Do not show browser app chrome

Set document title cleanly:
"[Job Number] - [Form Title]"

Validation:
- Open completed job form
- Click Print/PDF
- Confirm print preview looks professional
- Confirm answers, signatures and photos appear
- Confirm in-progress print shows DRAFT if allowed

- Publish after passing
