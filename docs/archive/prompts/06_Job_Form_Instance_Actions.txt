Fix Job Forms instance actions.

Current issue:
From Job -> Forms tab, users can start/generate a job form, and it appears under In Progress / Completed, but there is no clear option to open, complete, edit, view, print/PDF, or delete it.

Required behaviour:

Job -> Forms tab

Available Job Forms:
- Keep Start button.
- If there are existing in-progress forms for that template, still allow Start, but show count like "2 in progress".

In Progress / Completed section:
Each form instance row/card must show action buttons.

For status = In Progress:
- Open / Continue button
- Delete button
- Optional: Print Draft

For status = Completed:
- View button
- Print/PDF button
- Reopen / Edit button if user has permission
- Delete button if user has permission

Clicking Open / Continue:
- Opens the Form Runner with saved answers loaded
- User can keep filling it out
- User can Save Draft
- User can Complete Form

Clicking View:
- Opens completed form read-only
- Completed answers are visible
- No editing unless Reopen/Edit is clicked

Clicking Delete:
- Show confirmation: "Delete this form? This cannot be undone."
- Delete the form instance and its answers
- Refresh the Job -> Forms list

Form Runner:
- Must load by form instance ID, not only template ID
- Must save answers back to the same form instance
- Must not create duplicate instances when opening an existing in-progress form
- Complete button changes status to Completed
- Save Draft keeps status In Progress

API endpoints:
- GET /api/job-forms?jobId=...
- POST /api/job-forms/start
- GET /api/job-forms/:id
- PUT /api/job-forms/:id
- POST /api/job-forms/:id/complete
- DELETE /api/job-forms/:id

All endpoints auth protected, company scoped and job scoped.

UI:
- Make action buttons obvious on desktop and mobile
- Suggested row layout: Form name, Status badge, Started/completed date, Started/completed by, Actions

Validation:
- Start a job form
- Confirm it appears as In Progress
- Click Continue and enter answers
- Save Draft
- Leave and reopen the same form
- Confirm answers remain
- Complete form
- Confirm status changes to Completed
- Confirm View opens read-only
- Confirm Delete removes it
- Confirm starting another form creates a separate new instance
- npm run build
- Publish after passing
