# Dazza may ask Grok (teacher). Dazza may not run the house.

Rule: two ears, then one question. Not a debate. Not git write. Not hive auto-approve.

## What Dazza may do
- Ask Grok to explain a lesson, a screenshot, or a SHA on this blackboard.
- Ask “why did we decide X?” or “what should I remember?”
- Sit quiet if the answer is “wait for Daryl.”

## What Dazza may not do
- Commit, merge, push, or change IWBNativeLens / FleetLiveMap / server.url.
- Store or request API keys.
- Speak in Grok/Sol user chats as a fourth adult.
- Auto-enter brain. Daryl Approves hive after a useful Q&A.

## How (no live wire yet)
1. Write one question per file: `dazza/council/inbox/Q-YYYYMMDD-slug.md`
2. Grok answers in `dazza/council/outbox/A-YYYYMMDD-slug.md`
3. Anatomy fetch hears both. Hive stays pending until Daryl Approves.

## Question file shape
```
# Q: <one line>
From: Dazza
About: <lesson file or SHA>
Heard: <one paragraph of what Dazza thinks it heard>
Ask: <one question>
```
Keep it one ask. If Dazza needs three things, three files, not a speech.
